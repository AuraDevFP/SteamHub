STEAM HUB — PREMIUM EDITION

Содержимое:
- index.html — главная страница
- pages/ — 12 подробных тематических разделов
- assets/ — логотип, favicon и иллюстрации
- style.css, script.js — оформление и интерактивность

Публикация на GitHub Pages:
1. Распакуй архив.
2. Загрузи содержимое папки в корень репозитория сайта.
3. В настройках GitHub Pages выбери нужную ветку и корневую папку.

В разделы перенесены инструкции и ссылки с исходного Steam Hub, с редактурой потенциально устаревающих сведений. Даты распродаж из исходника помечены как требующие сверки с официальными новостями Steam.
Steam Hub — независимый справочный проект, не связанный с Valve Corporation.

Календарь: статусы «Прошла», «Ожидается», «Идёт сейчас» рассчитываются браузером автоматически каждые 30 секунд. Даты в списке не синхронизируются автоматически с Valve и требуют ручной сверки при изменениях.
